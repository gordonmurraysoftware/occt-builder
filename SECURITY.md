# Security

## Scope

This repository is the image recipe: the Dockerfile, the smoke test, and the workflows that publish `ghcr.io/gordonmurraysoftware/occt-builder`. A report belongs here when the recipe, the pin, or the publish path is wrong.

Bugs in OCCT, meshoptimizer, gltfpack, libwebp, or Debian belong with those projects. This image redistributes them; it does not patch them.

## Reporting

Use GitHub private vulnerability reporting: Security → Report a vulnerability on this repository. Do not open a public issue for an unpublished problem in the recipe or the publish path.

There is no bug bounty.
